Inputs and phase

Choose two different, independent properties from T, P, Q, H, S, D, and U. Input units are converted to SI before calling CoolProp. An unsupported pair or a state outside a fluid’s available range produces an error.

Pressure is absolute. Q = 0 means saturated liquid, Q = 1 means saturated vapour, and 0 < Q < 1 means a two-phase mixture. Quality is unavailable for single-phase states.

For a two-phase mixture, the calculator leaves viscosity, thermal conductivity, and specific heats unavailable. Select Q = 0 or Q = 1 to query each saturated phase.

MATLAB calls

The output selector below a result creates a call to your MATLAB getFluidProperty interface. Calls use SI inputs: kelvin, pascals, and joules per kilogram as applicable.

getFluidProperty(lib, 'H', 'T', 300, 'Q', 0, 'R134a')

Set up lib in MATLAB with your installed property library first. The website itself uses the bundled CoolProp WebAssembly engine and runs its calculations in a browser worker.
